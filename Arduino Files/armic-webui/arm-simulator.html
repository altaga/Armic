Warm-upPre-exercise dumbbell holds

Static curl positions for loading the dumbbell. Each command safe-homes first, then moves to the hold — same path logic as Home / Transport.

Dumbbell Up
Upright rest with load — identical to Home: joints near 90°, elbow at 95° so gravity does not hunt the soft limit.
base 90 · sh 90 · el 95 · wr 90
Dumbbell Down
Curl-down hold: shoulder forward, elbow fully folded, wrist pitched for the load. Use after grabbing the dumbbell with the claw.

ExercisesSingle exercise — default 6 reps

Each exercise runs 6 reps on the front (+X) side except Elbow Flexion, which works on the −X (left) side. Reps 1–5 loop the same pair; rep 6 may chain extra waypoints.

Bicep Curl
Shoulder 120° and elbow 170° locked. Only the wrist curls tip-down ↔ tip-up — isolated tip flip without moving the elbow hinge.
+X front · wrist 180° ↔ 25° · 6 reps · sh/el fixed
Lateral Raise
Two photo L-poses only: tip out ↔ tip down. Shoulder 90° and elbow 180° locked — same inverted-L column; only wrist tip direction changes.
90/180/90 ↔ 90/180/180 · 6 reps · +X front
Elbow Flexion
Only exercise on the −X (left) side — shoulder locked at 0°. Elbow and wrist flex together: EF-EXT (0/95/90) ↔ EF-PEAK (0/180/180). Reps 1–5: EXT → PEAK → EXT. Rep 6 chains HTL-4 → HTL-5 (no extra safe-home after).
EF-EXT → EF-PEAK ×5 · rep 6: EXT → PEAK → EXT → PEAK → HTL-4 → HTL-5

Showcase demos

Physics and motion highlights — not part of rehab.

Named PosesC pose and transport — checkpoint holds

Each pose homes first, then moves to the target. Use these as known checkpoints when chaining moves by name.

C Pose
Gentle open “C” in the sagittal plane — tip high and slightly forward. Showcase reach without folding into the floor or overloading the shoulder.
base ~90 · sh ~55 · el ~155 · wr ~150
Transport
Deep tuck for carrying load: upper arm vertical, forearm horizontal, tip straight down. Keeps payload close to the column — same carry pose used mid-way through Heavy Tucked Lift.
base 90 · sh 90 · el 180 · wr 180 · tip ↓

Demo DynamicsOne-shot physics demos — auto-finish then home

Finite moves that show torque, inertia, or packed-power strikes. Each runs once and returns to stable home when done.

Heavy Tucked Lift
Five-waypoint lift in one continuous S-curve — synced joints, no pauses. Safe-homes first, then HTL-1 through HTL-5 (tip over column at HTL-4). Ends at home.
HTL-1 (180,90,90) → HTL-2 (127,180,90) → HTL-3 (112,180,180) → HTL-4 (~30,180,180) → HTL-5 (90,90,90)
Pendulum Swing
Dynamic torque demo: dip the elbow to build momentum, snap up, then brake into stable home. Uses inertia instead of a slow deadlift — watch shoulder and elbow strain on the scope.
Extend → hold → dump → inertia swing → brake → home (el 95°)
Gimme Five
Single burst: coil → strike → retract → home. Same tuck-and-strike as Cobra Strike, but runs once — not a loop.
1 strike · brief hold · stable home

Demo SequencesContinuous loops — stop manually when done

Paths that keep running until you hit Stop Sequences. Good for stress tests and smooth-motion showcases.

Orbital Scan
True Cartesian control: IK traces a slow vertical circle while keeping the hand level (pitch 0). Proves on-device path planning is a smooth O, not a flat joint sweep.
Loop · 96 waypoints · ~6°/s joint advance
Snake Dance
Procedural joint-space wave: phase-shifted sines on base, shoulder, elbow, and wrist so fluid undulation travels down the links. Pure joint math — no IK.
Loop · sine phases · low shoulder torque band
Cobra Strike
Coil → strike → retract on repeat. Extreme joint-space snap from a deep tuck. Runs as a continuous loop until Stop Sequences (Gimme Five is the same move, once).
Loop · ~3 s pause between strikes
