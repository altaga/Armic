# Original image assets (backup)

Full-resolution copies of all `Images/` media **before** web optimization.

| | |
|---|---|
| **Created** | Automated backup before `scripts/optimize-images/` run |
| **Total size** | ~456 MB |
| **Working copies** | Optimized PNG/JPG/MP4 live in `Images/` (parent folder) |

Do not delete this folder unless you have another off-repo archive. Re-run optimization from these files:

```bash
cd scripts/optimize-images
npm install
npm run optimize
```
